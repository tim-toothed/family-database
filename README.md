# Базовый статический сайт для семейного древа

## Структура проекта

```text
.
├── index.html
├── styles.css
├── data/
│   └── people/
│       ├── P016.yaml
│       ├── P027.yaml
│       └── ...
└── js/
    ├── app.js
    ├── config.js
    ├── data-loader.js
    ├── graph.js
    └── renderers.js
```

## Как это работает

1. f
2. Сайт пытается загрузить файл `data/people/PXXX.yaml` для каждого ID.
3. Если карточка существует, человек отображается как кликабельный узел с деталями.
4. Если карточки ещё нет, имя всё равно участвует в графе, но полная карточка не откроется.
5. Связи строятся по полям `parents`, `siblings`, `spouses`, `children`.
